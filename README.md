# 字幕节奏校对台（Subtitle Rhythm Deck）

一个完全在本地 / 浏览器内运行的字幕时间轴校对工具：导入 **SRT 字幕** 与**浏览器可播放的音频**，
在同一时间轴上拖动字幕块的左右边界校准节奏。拖动时实时强制 **不重叠 / 最短时长 / 最小间隔** 三条约束，
越界操作会**自动回弹并标出原因**。

- React 18 + TypeScript + Vite，纯前端、无后端、无外部服务
- 字幕与音频均通过浏览器本地读取，**不会上传任何文件**
- Nginx 静态镜像 + Docker Compose 一键启动

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 导入 SRT | 兼容 `,` / `.` 毫秒分隔符、缺序号块、CRLF；解析异常逐块告警不中断 |
| 导入音频 | 任意浏览器原生可播放格式（mp3 / wav / m4a / aac / ogg / opus 等） |
| 本地静音分析 | 音频加载后用 **Web Audio API** 本地解码（不上传），按 **20ms 窗口**计算各声道 RMS 的最大值；低于可调阈值且连续 **≥200ms** 才形成静音段，间隔 **<80ms** 的段先合并 |
| 静音带叠加 | 静音段以斜纹带叠加在标尺与泳道上，拖动吸附命中的段会高亮 |
| 静音吸附 | 拖动字幕边界进入静音段边缘 **150ms** 范围即吸附到最近边缘，两侧等距取更早者；吸附结果仍须通过最短时长 / 最小间隔校验，不合法时**保留未吸附候选并提示原因**；工具栏提供吸附开关与可调阈值（dB） |
| 时间轴校对 | 拖动字幕块**左/右边界**手柄调整起止时间，毫秒级吸附（1ms） |
| 参考字幕差异审阅 | 在当前工作区之外**另导入一份参考 SRT**（不替换正在校对的字幕），两轨按时间顺序做**一对一单调配对**：仅去空白与标点后文本相同的条目才可配对，先**最大化配对数**、再**最小化配对起点时间差总和**，重复台词与单侧插入不会造成后续错位；列出**当前独有、参考独有、已配对但起止偏差超过可调阈值**的条目，点击条目**定位时间轴并展示两侧时间码**；切换当前 SRT 自动清空参考轨，参考文件与审阅状态**仅保留在当前页面内存**（不落盘、不进会话快照） |
| 阅读速度修复 | 按**去掉空白与标点后的 Unicode 字素簇数 ÷ 字幕时长**（字/秒）标出超过可调阈值的条目（列表行与时间轴块带 ⏩ 标记）；选中条目后目标时长按 `ceil(字数 ÷ 阈值)` 取整到毫秒，预览把所需延长量**先均分到起止两侧**，一侧受 **0s / 相邻字幕最小间隔 / 已加载音频终点**限制时把未分配量转给另一侧；两侧余量仍不足则**显示缺少的毫秒数并禁止提交（原字幕不变）**，余量足够时展示**新旧时间码**，确认后作为**一次历史操作**提交（可撤销/重做并参与现有 SRT 导出）；面板随当前字幕、约束与音频终点实时重算，切换 SRT 自动清空选择 |
| 音频活动空档审阅 | 复用本地音频的 **20ms 能量窗口**，按**可调电平阈值**提取连续高能量段并**合并短暂低能量断口**；当前字幕区间**先合并**、再带**可调边界容差**从活动段中扣除（重叠字幕不重复切割），只列出剩余时长达到**可调下限**的区间；显示起止时间与时长，**点击定位播放头试听**；字幕时间码、参数或音频变化后实时重算，无音频 / 分析失败时说明原因，切换音频旧结果即失效；**仅提示疑似未覆盖音频，不自动补字幕、不写入撤销历史** |
| 区间漂移校准 | 字幕列表 **Shift+点击** 选连续区间，以「首条起点 / 末条终点」为原始锚点输入目标时间，区间内全部起止时间做同一**线性映射**；时间轴实时预览旧/新位置与缩放比例；锚点倒序、映射后低于最短时长、相邻间隔不足即**禁止提交并定位首个冲突**；合法结果作为一次历史记录整体撤销/重做 |
| 三重约束 | 实时校验：不可与相邻字幕重叠、不短于「最短时长」、不小于「最小间隔」、不可越过 0s |
| 越界回弹 | 非法位置松手后块原样回弹，显示红色虚影 + 气泡说明具体原因（与上/下一条、差多少毫秒） |
| 约束参考线 | 拖动时黄色虚线标出当前边界允许的活动区间 |
| 点击定位播放 | 点击字幕块或列表中的时间码即跳转并播放；点击标尺/空白轨道定位播放头 |
| A-B 循环试听 | 以选中字幕起止 ± 可调前后余量形成循环区间，播放越过 B 点自动回到 A 点；切换选择保留开关并更新区间，播放头落在新区间外立即跳到新 A 点；时间轴标出 A/B 旗标与循环范围；无音频 / 未选字幕 / 区间裁剪后为空时禁用并说明原因 |
| 单句跟读对比 | 选中字幕并导入音频后一键跟读：申请麦克风 → 页面倒计时 3 秒 → **先启动麦克风录音、再从字幕起点播放原音**，到字幕终点（裁剪到音频结尾）自动停止；**录音只以 Blob URL 保存在当前浏览器会话内存中，不上传、不落盘**。回放时原音与录音同步启动，两轨各自独立的音量与静音控制；任一路暂停 / 结束 / 重新定位都联动另一轨，累计时钟偏差超过 **80ms** 即以原音时钟纠偏。录制期间自动暂停 A-B 回卷（开关状态保留，结束自动恢复）；切换字幕、导入新音频、重新录制或离开页面都会停止并释放旧 `MediaStream`、定时器与 Object URL；权限被拒 / 设备缺失 / 浏览器不支持均给出可恢复提示 |
| 撤销 / 重做 | 仅记录成功的边界调整；`Ctrl/⌘+Z` 撤销，`Ctrl/⌘+Shift+Z`（或 `Ctrl+Y`）重做 |
| 缩放 | 滑块在 10–400 px/s 之间无级缩放，横向滚动浏览 |
| 约束可调 | 工具栏实时修改最短时长与最小间隔（秒），立即对后续拖动生效 |
| 导出 SRT | 按时间先后重排并输出连续编号 `1..N`，文件名为 `<原名>.fixed.srt` |
| 帧率网格导出 | 把全部字幕起止点**联合吸附**到目标帧率（24 / 25 / 30 / 30000/1001 帧/秒）的整数帧：每个起止点取**最近帧（等距取较早帧）±2 帧**为候选，时间按**帧率分数**精确计算避免累计漂移；动态规划在全部候选边界上联合选帧——每条起止至少相隔 1 帧、输出毫秒时间码的时长与相邻间隔满足当前最短时长 / 最小间隔约束、起点不早于 0，先**最小化总绝对误差**、同分取**帧号序列字典序最小**；无解时指出首个无法接续的字幕及原因且**不导出部分结果**，有解时预览原/新时间码与总误差并下载 `<原名>.frame.srt`（帧时间四舍五入到毫秒，**原字幕与撤销历史不变**） |
| 本地会话恢复 | 字幕内容、**撤销/重做历史**、约束与视图设置变化后自动保存到浏览器 **IndexedDB**，每次快照带单调递增 **revision**，写事务内拒绝旧 revision 覆盖新状态；重新打开页面列出可恢复会话，恢复前**完整校验版本与数据结构，失败绝不改动当前工作区**；会话记录音频文件名 / 大小 / **SHA-256**，恢复后须重选同一音频、指纹匹配才重新启用播放（字幕编辑与导出不受等待影响）；支持删除会话与停用自动保存 |

> 说明：本工具专注「节奏」校对，即只调整时间码，不编辑字幕文本。
>
> 隐私：字幕、撤销历史与设置只写入**本机浏览器的 IndexedDB**；音频文件本身
> **永不落盘**（只记录文件名、大小与 SHA-256），无任何网络外发。

## 一键启动（Docker Compose）

需要 Docker 20.10+ 与 Compose v2。

```bash
docker compose up -d --build
```

### 入口与访问地址

| 入口 | 地址 |
| --- | --- |
| 应用入口（Docker Compose） | http://localhost:8080 （容器内 Nginx 托管，端口可用 `SUBTITLE_PORT` 修改） |
| 本地开发服务器 | http://localhost:5173 （`npm run dev`） |
| 本地生产预览 | http://localhost:4173 （`npm run preview`） |

停止：

```bash
docker compose down
```

### 配置

| 配置项 | 方式 | 默认值 |
| --- | --- | --- |
| 宿主机访问端口 | 环境变量 `SUBTITLE_PORT`（compose 自动插值） | `8080` |

换用 9090 端口的示例：

```bash
SUBTITLE_PORT=9090 docker compose up -d --build
# 访问 http://localhost:9090
```

容器内固定监听 80，由 Nginx 托管构建产物；无数据卷、无账号、无网络外发。

## 本地开发（不用 Docker）

需要 Node.js 20+。

```bash
npm install
npm run dev        # 开发服务器，访问 http://localhost:5173
npm run build      # 类型检查 + 产物构建到 dist/
npm run preview    # 本地预览生产构建，http://localhost:4173
npm run test:smoke # 纯 Node 冒烟测试：SRT、约束、静音检测与吸附、A-B 循环、跟读、区间漂移、参考差异配对、阅读速度修复、音频活动空档、帧率网格、SHA-256 与会话快照校验纯函数
```

## 使用步骤

1. 打开页面后点击 **导入 SRT**，选择字幕文件（解析告警会出现在右下角）。
2. 点击 **导入音频**，选择与字幕配套的音频。加载后会自动用 Web Audio API 解码并检测静音段（状态栏显示「静音分析中… / N 段静音」）；**更换音频会取消旧分析，旧结果不会回写**。
3. 用滑块调整合适缩放；鼠标悬停边界手柄可看到允许拖动范围。时间轴上的斜纹带即静音段。
4. 按住字幕块的**左/右手柄**拖动：
   - 边界进入静音段边缘 **150ms** 内时自动吸附（绿色吸附线 + 气泡），两侧等距取更早边缘；
   - 吸附点若违反最短时长 / 最小间隔 / 重叠约束，则**不采用吸附**，保留未吸附候选，并以气泡与提示条说明原因；
   - 合法位置松手 → 边界更新并进入撤销历史；
   - 非法位置松手 → 块回弹，红色虚影与气泡标明原因（重叠 / 间隔不足 / 时长不足 / 越过 0s）。
5. 工具栏可勾选/取消 **静音吸附** 开关，并用 **阈值（−60 ~ −20 dB）** 滑块调整静音判定电平；调阈值只对当前音频重新分段，无需重新解码。
6. 点击字幕块本体或左侧列表时间码，播放头跳到该字幕并开始播放。
7. 选中一条字幕后可开启工具栏的 **A-B 循环**：循环区间为「字幕起点 − 前余量 → 字幕终点 + 后余量」（余量可实时调整，A 不越过 0s、B 不越过音频结尾）；播放越过 B 点自动回到 A 点继续。切换选择时循环开关保留、区间随之更新，播放头落在新区间外会立即跳到新 A 点；暂停、导入新音频或关闭循环后，旧的播放回调不会再拉回播放头。未导入音频、未选字幕或区间经音频时长裁剪后为空时，开关禁用并显示原因。
8. **区间漂移校准**（批量平移/拉伸连续字幕）：在字幕列表普通点击一条字幕设定锚点，再 **Shift+点击** 另一条字幕选中连续区间（再次普通点击可收起）。下方出现「区间漂移校准」面板，以区间**首条起点、末条终点**为原始锚点，输入各自的**目标时间**（支持 `83.5`、`01:23.500`、`00:01:23,500` 等格式）后，区间内所有起止时间做同一线性映射。输入过程中时间轴实时显示**旧位置（半透明原块）/ 新位置（虚影）预览与缩放比例**；目标锚点倒序、映射后任一字幕低于当前最短时长、或与区间内外相邻字幕不满足最小间隔时，**应用按钮禁用并自动定位首个冲突**（红色预览 + 冲突气泡，可点「定位」再次跳转）。点击 **应用映射**（或 Enter）将合法结果作为**一次历史记录**提交，可整体撤销/重做并随现有流程导出 SRT；点击 **取消**（或 Esc）、切换字幕/音频文件都会清空区间与预览。
9. **参考字幕差异审阅**（拿另一份 SRT 做参考，不动当前校对内容）：点击舞台底部 **🆚 参考字幕差异审阅** 栏的 **导入参考 SRT**，选择参考文件。两轨自动按时间顺序做一对一单调配对——只有**去掉空白与标点后文本相同**的条目才会配对，算法先**最大化配对数**、再在并列方案中**最小化配对起点时间差总和**，因此重复台词或单侧多出/缺少的句子只会被标为独有，不会把后续全部带歪。面板分三类列出：**当前独有**、**参考独有**、**偏差超限**（已配对但起点或终点偏差严格大于右上角可调阈值，默认 0.5s），可用页签按类过滤。**点击任一条目**：当前侧有对应字幕的会在列表与时间轴中选中并移动播放头，参考独有条目直接移动播放头到参考起点；面板内同时显示**两侧完整时间码与 Δ 偏差**。再次 **更换参考** 可载入新参考轨；**清空参考** 或切换当前 SRT（以及恢复会话）都会清空参考轨；参考文件与审阅状态只存在于当前页面内存，刷新即消失，不进入 IndexedDB 会话快照。
10. **阅读速度修复**（给读得太快的字幕自动加长）：舞台底部 **⏩ 阅读速度修复** 栏列出所有速度超过右上角可调阈值（默认 **10 字/秒**）的条目；速度 = **去掉空白与标点后的 Unicode 字素簇数 ÷ 字幕时长**（NFKC 归一化，emoji 与组合字符各算一个字；恰好等于阈值不算超速）。字幕列表行与时间轴块上的 **⏩** 角标与面板条目一一对应。
    - **点击面板任一条目**：右侧出现延长预览——目标时长按 `字数 ÷ 阈值` **向上取整到毫秒**，所需延长量**先均分到起点侧与终点侧**（奇数毫秒多的 1ms 归终点侧）；
    - 一侧受 **0s、与相邻字幕的最小间隔、或已加载音频终点**限制而分不满时，未分配量**自动转给另一侧**，预览中逐侧标出实际延长量与触限原因（如「受下一条 #12 最小间隔限制」「已到音频终点」）；
    - 两侧余量合计仍不足时，预览显示**缺少多少毫秒**并将 **应用延长** 禁用，原字幕保持不变；余量足够时显示**原时间码与新时间码**，点击 **应用延长** 即把该条字幕的调整作为**一次历史操作**提交（`Ctrl/⌘+Z` 撤销、`Ctrl/⌘+Shift+Z` 重做，并随 **导出 SRT** 输出）；
    - 拖动过字幕、改过最短间隔 / 最小间隔、更换音频（终点变化）或调整速度阈值后，面板**自动重算**；再次点击同一条目或点 **取消** 收起预览；**切换当前 SRT / 恢复会话自动清空面板选择**（阈值保留在本页面内存）。未加载音频时终点侧不施加音频终点限制，并在预览中注明。
11. **音频活动空档审阅**（找出疑似没被字幕盖住的出声片段）：导入音频并完成本地分析后，舞台底部 **🔊 音频活动空档** 栏实时列出疑似未覆盖区间。面板复用静音分析的 **20ms 能量窗口**，按栏内可调的 **电平阈值（−60 ~ −20 dB）** 提取连续高能量段，并把短于 **合并断口**（默认 0.25s）的低能量断口并入两侧；随后把当前字幕区间先合并、再向两侧各扩 **边界容差**（默认 0.1s）从活动段中扣除，只列出剩余时长达到 **最短空档**（默认 0.5s）的区间。每行显示**起止时间码与时长**，**点击即把播放头定位到起点并播放试听**。修改字幕时间码、调整四项参数或更换音频都会**实时重算**；未导入音频、等待重选音频、分析中与分析失败都会在面板内说明原因，**切换音频后旧结果立即失效**。该列表仅作提示，不会自动补字幕，也不写入撤销历史。
12. 快捷键：`空格` 播放/暂停，`Ctrl/⌘+Z` 撤销，`Ctrl/⌘+Shift+Z` 重做（跟读录音进行中空格与时间轴点击会被暂时屏蔽）。
13. 舞台底部的 **🎤 单句跟读对比** 面板用于逐句模仿：
   - 选中一条字幕并已导入音频后点击 **开始跟读**：浏览器申请麦克风权限，随后页面 **倒计时 3 秒**；倒计时结束后**先启动麦克风录音，再从字幕起点播放原音**，到达字幕终点（自动裁剪到音频结尾）即停止，也可点 **提前停止** 落盘较短录音；
   - 录音完成后进入双轨回放：原音轨与录音轨**同步启动**，每轨有独立的音量滑块与静音按钮；
   - 任一路暂停 / 播放到结束 / 拖动进度条，另一轨都会联动；两轨累计时钟偏差超过 **80ms** 时自动以**原音时钟**把录音轨拉回对齐（面板右上角显示实时偏差）；
   - 可 **重新录制**（先释放旧录音的 MediaStream / 定时器 / Object URL 再开新一轮）或 **丢弃**；
   - **录音仅保存在当前浏览器会话内存中**（Object URL），刷新或关闭页面即消失，不会写入磁盘或上传；
   - 录制期间 A-B 回卷自动暂停（工具栏开关保持原状并显示「跟读录音中 · 已暂停回卷」），录音结束后按原开关状态恢复；切换字幕、导入新音频也会立即停止并释放旧录音资源；
   - 浏览器不支持录音、麦克风权限被拒绝、无设备或设备被占用时，面板显示具体原因，处理后可在原处 **重试**。
14. 点击 **导出 SRT**，得到按时间顺序重新编号的校对结果（等待重新选择音频期间导出同样可用）。
15. **帧率网格导出**（把整份字幕吸附到帧率整数帧后另存，不改动当前校对内容）：展开舞台底部 **🎞 帧率网格导出** 栏，选择**目标帧率**（24 / 25 / 30 / 30000/1001 帧/秒）。面板随当前字幕与「最短时长 / 最小间隔」约束实时重算：每个起止点取最近帧（等距取较早帧）及前后各 2 帧为候选，在全部候选边界上联合选帧。有解时列表预览每条的**原/新时间码**与帧号，底部给出**总误差**，点击 **导出 .frame.srt** 下载（帧时间四舍五入到毫秒，文件名 `<原名>.frame.srt`）；无解时面板标红显示**首个无法接续的字幕及原因**（可点「定位」跳转选中该条），导出按钮禁用、**不产出部分结果**。该导出为纯只读操作，**不修改字幕内容与撤销/重做历史**。

## 本地会话恢复（自动保存）

所有校对状态都保存在**本浏览器**的 IndexedDB 中（数据库 `subtitle-rhythm-deck`，store `sessions`），
不经过任何服务器：

- **保存内容**：当前字幕、**完整撤销/重做栈**、最短时长 / 最小间隔、缩放、静音吸附开关与阈值、
  A-B 循环开关与余量、当前选中字幕；以及音频的**文件名 / 字节数 / SHA-256 指纹**。
  **音频文件本身不保存**。
- **保存时机**：上述任一项变化后 **400ms 去抖**自动写入；页面隐藏 / 关闭前再尽力补刷一次。
  每次成功写入携带单调递增的 **revision**（`r1, r2, …`）。
- **防旧覆盖新**：写入在**同一个 IndexedDB readwrite 事务内**先读出已存记录，
  仅当 `revision` 严格更大时才 `put`；发现已存在更新的 revision（例如同一页面在另一个标签页
  被编辑过）立即 `abort` 事务拒绝覆盖，并自动停用本页自动保存、提示冲突，旧状态永远不会回写。
- **重新打开页面**：检测到本地存在会话时自动弹出 **🗂 恢复会话** 列表（也可随时点工具栏
  **🗂 恢复会话** 打开），按最近更新排序，展示字幕条数、撤销步数、revision、更新时间与音频指纹。
  - 点击 **恢复** 前会**再次**读取并做完整校验：结构版本（`schemaVersion`）、revision / 时间戳、
    每一帧字幕（id、时间、文本、无重复 id、撤销栈/重做栈与当前字幕 id 集合一致）、
    视图设置取值范围、选中字幕归属、音频指纹格式。
  - **任何一项校验失败都不会改动当前工作区**：损坏记录在列表中标红，只能删除（不能恢复）。
  - 从另一个会话切换恢复时，如果当前工作区有内容会先二次确认；确认后当前会话的待写快照
    会先落盘，再整体替换工作区（不存在半成品状态）。
- **音频重新匹配**：恢复后音频不会自动出现。工具栏下方出现提示条，点 **重新选择音频**
  （或用「导入音频」）选择原文件：浏览器本地计算 SHA-256，**大小 + 哈希一致**才装载并重新启用
  播放、A-B 循环与跟读（仅文件名不同但内容一致时会提示并接受）；不匹配则拒绝并保留等待状态。
  **等待期间字幕拖动、撤销/重做、区间漂移与 SRT 导出全部正常可用。**
- **停用自动保存**：工具栏取消勾选 **自动保存**（偏好记在 localStorage），此后不再写任何快照，
  已保存的会话保留；重新勾选即恢复。
- **删除会话**：在恢复列表中删除单条记录（当前正在编辑的会话需先导入其他 SRT 或关闭页面）。
- 清除浏览器站点数据（或 DevTools 中删除 IndexedDB）即彻底删除全部会话。
- 浏览器不支持 IndexedDB（个别隐私模式）时功能静默降级为纯内存工具，其余校对功能不受影响。


## 静音检测与吸附的精确定义

- **窗口能量**：解码后按 `20ms` 窗口遍历，对每个声道计算 RMS，窗口能量取**各声道 RMS 的最大值**（任一声道有声即不算静音）。
- **成段条件**：窗口能量**严格低于**阈值的连续窗口形成候选段；连续时长 **≥ 200ms** 才保留（恰好 200ms 合法）。
- **段合并**：两个候选段之间的非静音间隔 **< 80ms** 时先合并为一段（恰好 80ms 不合并），合并后再过最短时长过滤。
- **吸附规则**：边界原始候选时间 `t` 在某静音段边缘（段起点或段终点）**150ms 半径内**（严格小于）才吸附；取距离最近的边缘，距离相等时取时间更早者。
- **吸附校验**：吸附后的时间必须与未吸附候选走**同一套**约束校验（不重叠 / 最短时长 / 最小间隔 / ≥0）。吸附点合法则采用吸附；吸附点不合法则保留未吸附候选，并返回吸附点的具体违规原因。

## A-B 循环的精确定义

- **区间**：`A = max(0, 字幕起点 − 前余量)`，`B = min(字幕终点 + 后余量, 音频时长)`（时长未知时不裁剪 B）；余量负值按 0 计；`B − A < 0.05s` 视为空区间，循环不可用。
- **回卷**：循环激活且播放中，帧级监听发现 `currentTime ≥ B` 即跳回 A 继续播放；B 恰好等于音频结尾时由 `ended` 事件回卷。
- **进入**：开启循环或切换选择时，播放头落在 `[A, B]` 之外立即跳到新 A 点（保持当前播放/暂停状态）；落在区间内则不移动；仅调整余量不抢播放头。
- **失效**：暂停、导入新音频、关闭循环都会同步作废旧循环计划并取消帧监听，此后任何已排队的播放回调都不会再改动播放头。
- **禁用**：无音频、未选字幕、区间经音频时长裁剪后为空，三者任一成立即禁用开关并显示原因；已开启的循环进入待机，条件恢复后自动续用。

## 单句跟读对比的精确定义

- **录音时序**：点击「开始跟读」后先在用户手势链中 `getUserMedia` 申请麦克风（开启回声消除 / 降噪 / 自动增益），权限成功才显示 **3 秒** 倒计时；倒计时结束时**先** `MediaRecorder.start()`，**再**把独立原音轨 seek 到字幕起点并 `play()`（两轨使用各自独立的 `<audio>` 元素，不干扰主导航）。
- **自动停止**：录音区间终点为 `min(字幕终点, 音频时长)`（且与起点至少留 50ms）；帧级监听发现原音到达终点即暂停并 `recorder.stop()`；终点恰为音频结尾时由原音 `ended` 事件兜底（两路径幂等去重）。
- **存储范围**：录音分片聚合成 Blob 后只通过 `URL.createObjectURL` 生成内存 URL 供回放，不写 IndexedDB / localStorage / 文件；切换字幕、导入新音频、重新录制、丢弃或组件卸载时 `revokeObjectURL` 并停止释放全部 MediaStream 轨道。
- **双轨回放**：进入回放阶段时释放麦克风；原音与录音相对时间 1:1 映射（录音时长以其自身 metadata 为准，缺失时用区间长度兜底）。
- **联动**：任一路 `play` / `pause` 都带动另一轨同状态；任一路自然结束则两轨一起复位到起点；任一路被重新定位，另一轨 seek 到同一相对位置（`seeked` 为异步事件，用「对轨位置是否已对齐」而非同步标记来避免事件回环）。
- **纠偏**：回放期间以 rAF 读取两轨位置，偏差 `原音相对位置 − 录音位置` 的绝对值**严格大于 80ms** 时把录音轨重新定位到原音对应位置（恰好 80ms 不纠偏）。
- **与 A-B 循环的关系**：倒计时与录音期间强制使 A-B 回卷计划失效（同步置 inactive 并取消帧监听），但不改动用户的开关与余量设置；忙碌结束后若开关仍开启且区间有效，回卷自动恢复。
- **失败提示**：缺少 `getUserMedia` / `MediaRecorder` 判为浏览器不支持；`NotAllowedError` / `SecurityError` 提示去地址栏授权；`NotFoundError` / `OverconstrainedError` 提示检查设备；`NotReadableError` 提示设备被占用——除不支持外均提供原位「重试」。

## 区间漂移校准的精确定义

- **区间选择**：字幕列表普通点击设定锚点，**Shift+点击**另一行选中锚点到该行之间的连续区间（含两端，自动按时间排序，与点击先后无关）；再次普通点击任意行收起区间。锚点 id 失效（如切换文件）时区间自动作废。
- **锚点与映射**：原始锚点为区间**首条起点** `oldStart` 与**末条终点** `oldEnd`；输入目标起点 `newStart`、目标终点 `newEnd` 后，区间内所有起止时间 `t` 映射为
  `t' = newStart + (t − oldStart) × scale`，其中 `scale = (newEnd − newStart) / (oldEnd − oldStart)`。
  映射结果统一**四舍五入到毫秒**后再校验，保证「预览所见即提交所得」；区间外字幕保持原样。
- **预览**：输入可解析即实时预览——时间轴上原块半透明显示旧位置、虚影块显示新位置，并标出新锚点线与缩放比例（面板同步显示缩放与起点平移量）；存在冲突时预览整体变红、首个冲突字幕的虚影与列表行高亮。
- **禁止提交**（按时间序取**首个**冲突并自动定位到对应字幕）：
  1. 目标锚点非法（负值 / 无法识别）或原始区间长度为零；
  2. 目标锚点倒序：`newEnd ≤ newStart`；
  3. 映射后任一区间内字幕时长 **< 当前最短时长**；
  4. 与相邻字幕（区间内外，至少一端在区间内）间隔 **< 当前最小间隔**（重叠按负间隔一并报出）。
  时长 / 间隔**恰好等于**下限合法。两端都在区间外的相邻对未被映射改动，不参与冲突判定。
- **提交与历史**：仅在无冲突时可提交；合法结果作为**一次历史记录**进入撤销栈，`Ctrl/⌘+Z` 整体撤销、`Ctrl/⌘+Shift+Z` 重做，导出 SRT 走现有流程（按时间重排并连续编号）。
- **清空**：切换字幕 / 音频文件、点击「取消」或按 Esc 都会清空区间与预览；撤销 / 重做不清空预览，原始锚点跟随最新数据实时重算。

## 参考字幕差异审阅的精确定义

- **参考轨**：通过面板的 **导入参考 SRT** 载入，只进入审阅面板；不修改当前字幕、撤销/重做历史、音频与会话，也不会出现在导出的 SRT 中。参考轨文件解析复用同一套 SRT 容错解析（BOM / `,` 与 `.` 毫秒分隔符 / 缺序号块 / 逐块告警）。
- **文本比较键**：每条字幕文本先做 Unicode **NFKC** 归一化（折叠全角/兼容字符），再删除所有 Unicode 空白（`\s`）与标点（`\p{P}`）；比较键完全相同的两条字幕才允许配对（不做大小写折叠）。
- **一对一单调配对**：配对在两轨各自按 `(start, end)` 排好的时间序上**严格单调**——每条字幕至多参与一对、配对连线互不交叉。求解为标准 LCS 动态规划（允许配对当且仅当比较键相同），按字典序 `(配对数降序, 配对起点时间差总和升序)` 取最优：先让配对条数尽可能多，再在所有最多配对方案中最小化 `Σ|current.start − reference.start|`；计数与代价都相同的并列方案优先让更早的条目配对。重复台词因此按时间就近对齐，单侧插入 / 删除只留下局部独有条目，后续不会整体错位。
- **规模上限**：DP 正向只保留两行滚动数组、回溯指针矩阵按单元格 1 字节存储；当 `(当前条数+1)×(参考条数+1) > 25,000,000` 时拒绝载入并提示，不占用超大内存。
- **差异分类**：
  1. **当前独有**：当前轨中未参与配对的条目；
  2. **参考独有**：参考轨中未参与配对的条目；
  3. **偏差超限**：已配对但 `|Δstart|` 或 `|Δend|` **严格大于**可调阈值（默认 0.5s；恰好等于不列出）的条目。差值按毫秒整数比较以吸收浮点误差；偏差未超限的配对不列出。三类条目按所在侧起点时间混排，可用页签过滤。
- **定位**：点击条目时，偏差超限 / 当前独有条目会选中对应当前字幕、强制列表与时间轴滚动定位，并把播放头移到该字幕起点（不强制播放）；参考独有条目当前轨无对应字幕，仅把播放头移到参考条目起点。点击后面板顶部固定展示**当前与参考两侧的完整 SRT 时间码**及带符号的 Δ 起点 / Δ 终点。
- **生命周期**：参考轨与阈值、过滤、定位等审阅状态**只存在于当前页面内存**——不写入 IndexedDB 会话快照、不写 localStorage、不触发自动保存；**切换当前 SRT（导入或恢复会话）时参考轨自动清空**，刷新 / 关闭页面同样消失。校对中调整时间码或文本会实时重新配对 / 重新分类，无需重新导入参考文件。

## 阅读速度修复的精确定义

- **字数**：字幕文本先做 Unicode **NFKC** 归一化（折叠全角/兼容字符），删除所有 Unicode 空白（`\s`）与标点（`\p{P}`），再按 **Unicode 字素簇**（`Intl.Segmenter` 的 `grapheme` 粒度；极端环境不支持时退化为按码点计数）计数——emoji（含 ZWJ 家庭序列）、组合字符各算一个字。字数为 0（纯标点 / 空文本）的条目不参与判定。
- **超速判定**：速度 = 字数 ÷ 当前时长（字/秒），时长按毫秒整数比较；速度**严格大于**阈值（默认 10 字/秒，面板可在 0.1–60 之间调整，恰好等于不标出）即列入面板并在列表行 / 时间轴块标 ⏩。
- **目标时长**：`ceil(字数 ÷ 阈值 × 1000)` 毫秒（1e-6 吸收浮点误差，整除时不误加 1ms），且不短于当前时长；**所需延长量 = 目标时长 − 当前时长**。
- **两侧余量**（毫秒，含当前「最小间隔」约束）：
  - 起点侧余量 = `start − max(0, 上一条.end + minGap)`（无上一条时左限即 0s）；
  - 终点侧余量 = `min(下一条.start − minGap, 已加载音频终点) − end`，两个上限按存在者取更早；未加载音频且无下一条时余量无限。
- **分配**：所需延长量先均分两侧（`floor(n/2)` 给起点侧，奇数毫秒多的 1ms 归终点侧）；一侧初始份额超过其余量时按余量取满，未分配量全部转给另一侧（另一侧随后触限也同理回转；两轮内收敛）。两侧都取满后仍未分完的量为**缺口毫秒数**。
- **禁止提交**：缺口 > 0 时预览标红显示缺少的毫秒数、两侧触限原因与「约束内可达」时间码，**应用按钮禁用，不修改任何字幕**。
- **提交与历史**：仅在缺口为 0 且确有延长量时可提交；结果只改动该条字幕的起止（其余条目引用不变），作为**一次历史记录**进入撤销栈，`Ctrl/⌘+Z` 整体撤销、`Ctrl/⌘+Shift+Z` 重做，导出 SRT 走现有流程（按时间重排并连续编号）。
- **重算与生命周期**：面板指标随当前字幕（含其他面板/拖动造成的时间码变化）、阈值实时重算；延长预览另随最短间隔约束与已加载音频终点实时重算。阈值与面板选择仅存在于当前页面内存，**切换当前 SRT（导入）或恢复会话时清空面板选择**；阈值不写入会话快照。

## 音频活动空档审阅的精确定义

- **能量来源**：复用静音分析已算出的 **20ms 窗口能量**（各声道 RMS 取最大值），不重复解码音频；与静音判定互补——窗口能量 **≥ 电平阈值**（恰好等于也算）即视为活动窗口。阈值在面板上以 dB 可调（−60 ~ −20，默认 −40 dB）。
- **活动段**：连续活动窗口形成候选段；两段之间的低能量断口**严格小于**「合并断口」（默认 0.25s）时合并为一段（恰好等于不合并），与静音段合并规则同构。
- **字幕扣除**：当前字幕区间先按时间排序并**合并重叠 / 相接区间**（避免重叠字幕被重复切割），再向两侧各扩「边界容差」（默认 0.1s，起点不越过 0s）后从活动段中逐个扣除；端点恰好相接不算交叠。
- **列出条件**：扣除后剩余时长 **≥ 最短空档**（默认 0.5s，恰好等于也列出，1e-9 吸收浮点误差）的区间才入列表；每行显示起止时间码（`00:00:00,000`）与时长，点击定位播放头到起点并播放试听。
- **重算与生命周期**：字幕时间码（含拖动 / 撤销 / 其他面板提交）、四项参数或音频任一变化即实时重算；未导入音频、恢复会话等待重选音频、分析中、分析失败分别在面板内说明原因；**切换音频 / SRT / 恢复会话时窗口能量立即清空并重新分析，旧结果不会残留**。四项参数仅存当前页面内存，不写入会话快照。
- **只读提示**：列表仅提示疑似未覆盖的音频区间，**不自动补字幕、不修改任何数据、不写入撤销历史**。

## 本地会话恢复的精确定义

- **快照内容**：`{ past, present, future }` 完整历史（与 `cues.ts` 的 `HistoryState` 同构）、
  约束（最短时长 / 最小间隔）、视图（缩放 10–400 px/s、吸附开关、阈值 −60…−20 dB、
  A-B 开关与 0–10s 余量、选中 id）以及 `srtName`、音频 `AudioFingerprint`；
  播放头、播放状态、静音分析窗口能量、跟读录音等临时态不持久化。
- **revision 与 CAS**：首帧快照 revision=1，每次成功写入严格 +1。`putSession` 在**同一
  readwrite 事务**内 `get(id)`：记录不存在直接写入；已存在且 `stored.revision >= 待写.revision`
  时 `tx.abort()` 并返回 `{ written: false }`，调用方据此停止本页自动保存——**旧 revision
  在任何时序下都不能覆盖新状态**。
- **去抖与补刷**：任一持久化字段变化后 400ms 去抖；写入进行中再次变化则标记 queued，
  落盘后用最新状态补刷一次；`pagehide` / 页面转 hidden 时取消计时器并立即补刷。
- **恢复校验（先校验、后改动）**：`schemaVersion` 必须等于当前版本；revision 为非负整数、
  `updatedAt ≥ createdAt`；present 非空且每条 cue 的 id 唯一、start≥0、end>start、text 为字符串；
  past / future 每帧都通过同样校验且 **id 集合与 present 完全一致**（历史栈只允许时间码差异）；
  视图各字段在取值范围内、selectedId 属于 present；音频为 null 或 `{ 非空 name, 非负整数 size,
  64 位小写 hex sha256 }`。任一项失败即整体拒绝，**不执行任何 setState**。
- **音频指纹**：指纹用纯 TypeScript SHA-256（`sha256.ts`，FIPS 180-4）对文件字节计算，
  不依赖 `crypto.subtle`（经 `http://<IP>:8080` 访问时非安全上下文无 SubtleCrypto）。
  恢复后重选音频时先比字节数、再比 SHA-256，两者一致才装载；文件名仅作展示与差异提示。
- **会话生命周期**：每次「导入 SRT」产生一个新会话 id（新 revision=0 起步，上一文件的音频状态清空）；
  空白工作区不落盘；删除按主键幂等；自动保存开关存于 localStorage 键
  `subtitle-deck.autosave`（`"0"` = 停用）。

## 帧率网格导出的精确定义

- **帧率分数**：目标帧率以分数 `num/den`（帧/秒）表示——24/1、25/1、30/1、30000/1001；帧 `n` 的精确时间为 `n·den/num` 秒。全部时间比较与误差累计都在该分数域内以**整数**完成，不做逐帧浮点累加，避免累计漂移；仅最终输出时把帧时间**四舍五入到毫秒**（半毫秒进位）。
- **候选帧**：每个起止点（毫秒整数）取**最近帧**——帧位置 `ms·num/(1000·den)` 与相邻两帧等距时取**较早**帧——及其前后各 2 帧，共至多 5 个候选；负帧（早于 0s）直接排除，故方案起点不早于 0。
- **联合选择**：全部字幕按时间序展开为 2N 个边界（起、止交替），动态规划逐边界选帧，约束：
  1. 每条字幕终点帧 ≥ 起点帧 + 1（起止至少相隔 1 帧）；
  2. 输出**毫秒时间码**的时长 ≥ 当前最短时长、相邻字幕间隔 ≥ 当前最小间隔（恰好等于合法）；
  3. 起点不早于 0。
  目标：先**最小化全部边界相对原时间码的绝对误差总和**（`|帧时间 − 原时间|` 在分数域精确求和），同分取按字幕顺序排列的**帧号序列字典序最小**者。每个边界状态只保留「误差最小、并列时字典序最小」的最优前缀，局部最优即全局最优。
- **无解**：报告按时间序**首个无法接续的字幕边界**及原因（与上一条的间隔 / 本条时长最大可达值与约束的差距），不生成、不导出任何部分结果；可调整约束或更换帧率后重试，面板实时重算。
- **导出**：有解时面板预览每条原/新时间码、帧号与总误差；导出按时间重排、连续编号 `1..N` 的 `.frame.srt`（帧时间四舍五入到毫秒）。原字幕、撤销/重做历史与会话快照均不受影响（纯只读导出）；帧率选择只保留在当前页面内存，不写入会话快照。

## 约束规则的精确定义

设被调整字幕为 `C`，时间轴上相邻的上一条为 `P`、下一条为 `N`：

- 拖动左边界到 `s` 时必须满足：
  `s ≥ 0`、`s ≤ C.end − 最短时长`、
  `P` 存在时 `s ≥ P.end + 最小间隔`（该条件同时排除了重叠）。
- 拖动右边界到 `e` 时必须满足：
  `e ≥ C.start + 最短时长`、
  `N` 存在时 `e ≤ N.start − 最小间隔`。
- 任一条件不满足则不修改数据（回弹），并返回第一条被违反规则的说明。
